# RollingStone500

RollingStone500 是一个面向音乐爱好者的静态专辑浏览与收听清单站。网站以 [《Rolling Stone》2023 年 12 月更新的“500 Greatest Albums of All Time”](https://www.rollingstone.com/music/music-lists/best-albums-of-all-time-1062063/) 为基础，按官方排名展示 500 张专辑的排名、艺人和英文专辑名，并为每张专辑提供“在 Apple Music 中打开”的入口。

## 当前状态

仓库目前处于原型阶段，README 已收录官方榜单的 1–500 条专辑；前端页面和逐张人工核验的 Apple Music 专辑页链接尚未提交。下面的内容描述网站的目标功能和实现约定。

## 计划功能

- 浏览按排名排列的 500 张专辑，并按艺人、专辑名或排名搜索和筛选
- 在每张专辑后显示 Apple Music 链接，直接打开对应专辑页面
- 标记“听过 / 在听 / 想听 / 弃了”，进度保存在浏览器本地
- 查看年代分布、艺人上榜次数和清单完成度等统计
- 支持通过文本或 JSON 导入其他音乐清单

## Apple Music 链接

专辑数据建议保留一个可选的 `appleMusicUrl` 字段。链接生成和匹配按以下顺序处理：

1. 优先使用已经人工确认的专辑链接；
2. 没有固定链接时，使用 iTunes Search API 根据艺人名和专辑名匹配 Apple Music 专辑 ID；
3. 匹配不到时显示 Apple Music 搜索入口，或明确标记为“暂未找到”，不伪造链接。

Apple Music 的目录和可用性取决于地区、版本（豪华版/重制版等）以及 Apple 的页面变更，因此自动匹配结果需要抽样复核。本站只提供外部链接，不托管或分发音频。

下面的榜单条目均已附 Apple Music 入口：已匹配到可靠 `collectionViewUrl` 的条目标为“Apple Music 专辑页”，其余条目标为“Apple Music 搜索”。搜索入口可直接打开 Apple Music 并定位到对应艺人和专辑。

示例数据结构：

```json
{
  "rank": 1,
  "artist": "Marvin Gaye",
  "album": "What's Going On",
  "appleMusicUrl": "https://music.apple.com/us/album/whats-going-on/1538081586"
}
```

`appleMusicUrl` 可保存经过人工核验或 API 匹配的正式链接；地区或版本不确定时，使用搜索链接更稳妥。

## 部署

目标是部署到 GitHub Pages 的纯静态站点。仓库 Settings → Pages → Source 选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/ (root)`。如果仓库名为 `RollingStone500`，站点地址通常是：

```text
https://<用户名>.github.io/RollingStone500/
```

部署到子路径时，页面资源请使用相对路径，避免以 `/` 开头的绝对路径导致 404。
